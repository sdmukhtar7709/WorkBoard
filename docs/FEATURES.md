# WorkBoard Features

## MVP Features
- Authentication screens for login and registration.
- Main app navigation with structured routes.
- Dashboard, jobs, categories, and profile pages.
- Reusable layout and UI primitives.
- Responsive frontend experience.

## Phase 2
- Real authentication flow integration.
- User profile editing.
- Job creation, editing, and deletion.
- Category management and filtering.

## Phase 3
- Backend-driven data loading.
- Persistent job and category storage.
- Activity history and user preferences.
- Stronger dashboard insights.

## AI Features
- Smart job summaries.
- Priority suggestions.
- Productivity insights.
- Natural-language assistance for organizing work.

## Browser Extension
- Quick job capture from the browser.
- Save useful pages into WorkBoard.
- Fast link and note collection.

## Resume Manager
- Store resume versions.
- Track revisions and updates.
- Organize resumes by role or application.
- Support future export and attachment workflows.
