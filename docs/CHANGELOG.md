# WorkBoard Changelog

## Semantic Versioning
WorkBoard should follow semantic versioning:
- `MAJOR` for breaking changes.
- `MINOR` for new backward-compatible features.
- `PATCH` for backward-compatible fixes and documentation updates.

## Initial Release Notes
### v0.1.0
- Created the initial frontend foundation for WorkBoard.
- Added Tailwind CSS v4 and React Router setup.
- Introduced reusable UI components and layout patterns.
- Added authentication screen layouts and route structure.
- Documented the product vision, API plan, database plan, and UI direction.
