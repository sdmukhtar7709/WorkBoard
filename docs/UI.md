# WorkBoard UI System

## Design System
WorkBoard should use a clean, modern, and professional interface with strong hierarchy, generous spacing, and consistent reusable components.

## Color Palette
- Background: slate-based dark surfaces for depth and focus.
- Primary accent: cyan for interactive elements and active states.
- Neutral text: soft slate tones for body content.
- Cards and borders: layered slate shades to separate content without heavy contrast.

## Typography
- Use a simple, high-legibility sans serif system.
- Keep headings bold and compact.
- Keep body text readable on both mobile and desktop.
- Use clear size separation between page titles, section labels, and helper text.

## Components
- Button: primary call to action and form submission.
- Input: reusable form field with label and consistent focus states.
- Card: surface container for auth and content blocks.
- Navbar: top-level navigation for app pages.
- AuthLayout: centered layout for login and register pages.

## Layout
- Use a centered container for primary app content.
- Keep navigation at the top for app-wide routes.
- Use a separate centered layout for authentication screens.
- Keep cards and page content aligned to the same width system.

## Responsive Rules
- Mobile-first spacing and typography.
- Stack navigation items cleanly on smaller screens.
- Keep auth cards full-width on mobile with comfortable padding.
- Limit content width on large screens for readability.
- Ensure forms remain usable without horizontal scrolling.
